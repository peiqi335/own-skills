# 助手引导与续接

## 启动

用户只给路径和“启动 paper2ppt 工作流”即可。先核实材料和已有任务，再说明实际来源、目录与下一步，例如：

> 已找到这篇论文及转换材料。我会先完整阅读，再带你理解问题和证据，一起确定主线。文件保存在「实际目录」。还需要了解汇报时长、听众和关注问题；暂时没想好可以按默认来。

只问尚缺且有用的信息，尽量合并一次。已知原图、简约、中文和目录偏好不重复问。“按默认来”“暂时没想好”或部分回答均可，其余按默认并说明，不连续追问。来源身份不能默认猜测。

依宿主工具发问，等待期间继续独立阅读/核查；需要科学判断的回答不能用等待时间替代。

## 全貌与聚焦

先说明问题、动机、设计、全部结果分布、核心证据、边界，再主动推荐有价值的入口并先解释：

> 最值得先看 Fig. 2，它影响作者是否排除了另一种解释。我先说明分组和比较关系。

一次一个主题，可合并关联小问题。不逐项考问，不要求用户对无分歧内容反复表态。完整笔记通过链接提供，聊天按理解需要讲解。

| 用户表达 | 行为 |
|---|---|
| 这个地方没懂 | 换解释方式，回到原图分组、指标和具体比较，不只是重复术语 |
| 先讲 Fig. 2 | 转到该图并补上下文，保留其他未决点 |
| 方法详细一点 | 回查条件及设计作用，再返回原讨论位置 |
| 这个结论是不是太强 | 核查支持程度，区分观察/解释/因果，提出证据和备选表述 |
| 懂了，继续讲 | 推进讨论，不授权制作 |
| 先停一下 | 保存当前阶段、未决点与下一步，停止推进 |

## 主线确认

关键疑问解决后主动收敛：顺序、原图、取舍理由、限制、估算时间，并说明沿用原文还是讨论重组。例如：

> 建议按「本篇具体主线」讲。如果认可，可以说“按这个主线制作”；也可以直接调整重点。

不要求口令。“就按这个做”“主线可以，开始制作”均有效。“可以”须对应明确问题。单独“继续”仅在前文唯一明确下一步是确认该主线并开始制作时可视为确认，有歧义简短澄清。不能将“图懂了”升级为制作许可。

忠实记录确认的具体主线及用户表达，不把助手提案写成批准。已有授权不重复问；明确直接完成时按主入口处理。

## 制作与恢复

制作只汇报有意义的发现或限制，不让用户逐页决定普通布局。源冲突影响结论时提出具体位置与建议。

“继续这篇”“从上次主线继续”：从文件恢复，简述阶段及下一步，不让用户重述历史；多个候选才请其选择。“改 Fig. 3 那页”：局部回查，不重走精读，保留旧 PPT 并交付新版本。
