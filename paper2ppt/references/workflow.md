# 阶段工作流

交互见 [引导](guidance.md)，持久记录见 [任务文件](task-files.md)。

## 1. 识别材料

只读核对指定主 PDF、转换全文、图像及补充材料的身份和版本。多个候选无法区分时列出具体文件请用户选择，不扩成多篇。通过 DOI/源哈希查已有任务。

身份核实后建任务目录和进度，展示路径。一次询问尚缺的时长、听众、重点；默认中文课题组、15–20 分钟、无预设重点。默认仅影响讲解与制作，不缩小阅读。先检查阅读条件，可提前报告制作能力缺口，不因此停止阅读。

## 2. 完整精读与理解核查

按 [精读](close-reading.md) 覆盖全部材料，逐步写笔记。先读再取舍。来源充分性 `full-paper` / `partial-paper` / `notes-only` 与实际阅读、理解状态分别记录；持有全文不等于读完。

材料不足时可提供明确标注的阶段性讲解，但不宣布完整精读完成。源内可解决的疑点自行回查，需要用户科学判断的留给讨论。

## 3. 全貌与聚焦讨论

先讲问题、动机、设计、全部结果分布、核心证据及限制，再每次聚焦一个主题。助手先解释，不粘贴整份笔记或让用户做阅读作业。把有效讨论与未决问题写入讨论文件。

## 4. 原文逻辑与主线确认

建立“问题—设计依据—实验/分析—观察—解释—下一步—结论边界”的联系及出处，标明作者明确、上下文支持、汇报组织建议或逻辑断点。保留并列结果，不将章节先后说成因果。

原文清晰时沿用；不清晰时列出断点、提出有据方案，由双方讨论确定。[论文类型](paper-types.md) 仅辅助。

完整精读后才拟定取舍。提交主线、图表、重点、拟省略内容及理由、限制和时间估算。检查全部主要结果去向，特别是反例、阴性结果及限定。按引导规则取得明确确认，记录所确认内容和用户的自然语言依据。

## 5. 安排与制作

确认后连续执行：制作预检 → 逐页安排 → 原图提取/核对 → 可编辑 PPT 和备注 → 验收。不增加逐页审批。逐页记录目的、标题、主张、图/分图、读图说明、限定、过渡及时间估算。

遵循 [原图](original-figures.md) 和 [排版](slide-design.md)。拆页、字号、布局自行处理；新证据改变主线/科学结论时暂停相关部分重议，其他工作继续。

重要但无法展开的细节可进备注或必要备份页，不强制添加备份页；会改变结论的限定必须在相关页说明，不能只藏备注或附录。

## 6. 检查与交付

按 [质量门](quality-gates.md) 核查阅读、理解、逻辑、内容、结构、视觉和讲述。修订实际 PPT/构建源，复查受影响项；全局改变才扩大检查，最终全部页面须有当前有效视觉证据。

导出未占用正式版本，更新验收与进度链接。交付实际文件和限制，不声称未执行的试讲或具体软件打开验证。

## 恢复与修订

先读进度、确认主线和当前阶段文件。源身份/哈希变化时核查影响，不把旧稿套新论文。局部修改只回查相关页、来源和上下文，导出新版本；主线变更只讨论受影响部分，保留其他决定。
