# 助手引导与续接

## 启动和解释

核实材料与已有任务后，说明来源、目录和下一步。只问尚缺且有用的信息，能采用默认的普通选择不连续追问；来源身份不能猜测。

先把摘要对照、引言、主线框架和配图正文讲给用户。用户问“这一步让我干什么”时，明确当前待判断的具体方案和需要其决定的分歧，不能把覆盖核查、查出处、排版等助手职责交给用户。

用户表示不理解时，回到样本是谁、实验怎样开展、数字对应谁、单位和分母是什么，再换解释方式。类比用于辅助，随后必须映射回本文实验；不能只换术语、重复定义或持续压缩。解释的操作细则见 [精读](close-reading.md)。

| 用户表达 | 行为 |
|---|---|
| 先讲某图 / 方法详细一点 | 转到相关图和样本、方法、图注，补上下文后回到原讨论位置 |
| 这个结论是不是太强 | 核查证据，区分观察、作者解释与推断，提出有边界的表述 |
| 逻辑太空 / 不知道怎么选 | 展示原顺序与新顺序、具体图表/实验及变化理由 |
| 懂了，继续讲 | 推进解释，不授权制作 |
| 先停一下 | 保存阶段、有效决定、未决点与下一步，停止推进 |

答疑结果回填笔记，后续分页承接，不要求用户重复指出同一个缺口。

## 两个确认节点

1. **主线确认**：提交问题分组、证据顺序、覆盖和主要取舍。用户确认后进入逐页方案。
2. **分页确认**：提交实际页标题、问题归属、原图表和上屏解释；每个结果页写明样本、分组、处理、测量与重复。用户确认后连续制作与验收，不再逐页询问普通排版选择。

不要求固定口令。依据用户表达和前文具体问题判定授权：“主线可以，先看分页”只授权分页；“分页没问题，开始做”授权制作；“按这个主线直接做完”已覆盖后续制作，不强加第二次停点。“继续”仅在下一步唯一明确时推进，否则只澄清确实影响授权的部分。

记录确认内容及自然语言依据。默认两次确认是可被当前指令覆盖的流程，不是每次修订都要重新审批；已有授权持续有效。

## 制作和修订

制作只汇报有意义的发现、限制和影响。科研结论改变时提出具体出处和建议，不把普通拆页/字号变成审批。

“继续这篇”：从记录和当前文件恢复，不让用户重述历史；候选不唯一时才问。

“我手改了，按当前版继续”：先读取实际 PPT 与有效决定；若与旧计划不同，识别并保留手改，不擅自判为错误回滚。按 [任务文件](task-files.md) 保护基准并同步后续记录。

“改某页”：只回查相关来源、页和上下文，核查跨页共用术语/标签。明确要求就地改时不另造交付副本；清理旧版须有具体范围授权。
