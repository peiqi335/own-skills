# 成品标准与验收

## 固定视觉锚点

用户确认 `assets/cat1-standard/` 为后续技能标准：02 区尺标下有独立基因绿条，其下为合并转录本/CDS 一行（与人/鸡/羊默认层级一致，不是 Show all 三行）。该目录有官方原始 SVG、元数据和输入 spec，可在不联网的情况下回放。`sha256.json` 用于证明当前冻结参考未变；不要为了让测试通过覆盖参考图。更新冻结须用户明确授权。工作副本 `06.GDV/CAT_1增强示例/` 不是技能冻结目录。

它是**展示标准**，不赋予冻结数据最新性或实验结论效力。

冻结参考原件及早期增强 SVG 中保留了当时的 NCBI 字体导入，复制它们是为了保存原样标准，不代表其 XML 已完全去除外链。新排版器在生成新成果时移除已知在线字体导入，采用本地字体；验收新成果的离线性，不能照抄冻结 SVG 的全部外围样式。

## 必须保留的信息层级

| 区域 | 视觉与内容要求 |
|---|---|
| 页眉 | 白底，顶部细青绿色条；醒目基因座、中文物种与染色体；次行拉丁名、assembly/version、sequence accession |
| 坐标 | 完整窗口数字、单位 bp、闭区间长度；不能只写约 142.7M 隐去精确坐标 |
| 01 定位 | 浅灰全序列长度条、两端坐标、红色窗口中心标记；明确加宽示意，不虚构带型 |
| 02 轨道 | 真实官方矢量嵌入：尺标、F/R、独立基因绿条（其下为转录本/CDS）、Ensembl、RNA-seq、变异；不可用类别明确说明。绿条不是 01 定位条，也不是 03 外显子轴。轨道顺序严格遵循生物学层级（RefSeq → Ensembl → RNA-seq → Variants），禁止出现 RNA-seq 或变异倒挂置顶 |
| 03 标记 | 红蓝/来源指定色；各段坐标和长度清楚；分段不合并成跨内含子连续引物。若填写 `exons`，同轴画出 RefSeq 外显子方块与 `exon N`，并写明转录本 |
| 页脚 | 获取日期、官方轨道+本地排版身份、简明证据边界；完整来源在随附说明 |

CAT_1 冻结增强页宽 1700；官方源基准导出宽度为 **1094 px**（导出时 GDV 面板宽，viewBox 为 `0 0 1094 ...`）。在 1700 画布中等比缩放约为 1.44 倍，确保官方 12px/10px/8px 字体与线条放大至 17px/14px/11.5px 保持舒适可读。严禁采用 1574 px 无缩放硬编码导出导致元素过度细小。排版器按实际轨道高度和标记数调整最终高度，并把官方 viewBox 缩放到页内轨道区。增加画布留白/高度优先于压小所有文字；不垂直变形官方轨道。

色彩沿用 `#0f766e` 青绿色分区、`#0f172a` 深色标题、白底及灰色细分隔线。官方轨道本身的颜色和渐变保持原样。默认中文用可嵌入的 Noto Sans CJK SC；不能把缺字截图当成通过。

## 四道验收门

### A. 来源和坐标

- URL、网页和原始 SVG 指向同一序列与窗口；窗口端点差异有明确说明。
- 染色体长度来自该 accession 的元数据，不沿用 CAT_1 的 205,367,284。
- 标记名称、颜色、每段端点与来源一致；外侧跨度只作为计算值。`mk` 含 `exN` 时，N 必须等于所选 `XM_`/`NM_` 上该段落入外显子的 `order`；02 区尺标与 03 区同名，不能只改 03 区显示。
- 不通过“数值看起来差不多”容忍版本错配或 1 bp 平移。官方标题可替换，但不随手平移轨道修标题。
- Ensembl release 不被静默改成搜索结果里更“新”的 release。

### B. 真正的轨道与科学边界

- 看到模型/曲线/特征而不只是标题；加载失败不标成无数据。
- 已核查缺失显示明文，不用空白占位冒充完整六轨。
- 多转录本折叠和窗口外截断在说明中保留，不称为完整全基因模型。
- 公共 RNA-seq、不确定的组织适用性、数据库变异与样本状态保持区别。
- 没有进行逐条比对时，不写“Ensembl验证一致”“引物无SNP”“已证实特异性”。

### C. 真实视觉验收

1. 实际查看增强 PNG 全图，对照固定标准。确认 02 区尺标下有独立基因绿条，其下只有一行合并转录本/CDS；不要把 01 定位条或 03 `exon N` 当成绿条，也不要把 Show all 三行当成达标。
2. PDF 独立渲染后实际查看，不能只看 SVG 的 PNG。看中文、数字、上下标、长 accession 是否缺字或裁剪。
3. 至少放大检查 F/R 与标尺、变异区及最右侧标签。有 `exN` 时核对 02 区官方尺标与 03 区是否同号。窗口边缘官方标签截断可保留但要说明；新增标题/标签不能被页边遮挡。
4. 检查新图全部轨道与官方图的相对位置一致；局部引物示意不能与原图不一致。
5. 如果画面不达标，修正并重渲。记录实际看过哪些文件，不把 XML 存在/哈希相同/退出码 0 当作看图。

工具无法提供图像输入时，把视觉检查标为未完成并说明，不能用模型自信替代视觉证据。

### D. 归档和交付

- 原始输入哈希前后相同，旧成品未改。
- SVG 无远程图像、字体/CSS URL、脚本依赖；PDF、SVG 都是矢量而非整页截图。
- 来源说明可追踪组装、窗口、标记、版本、日期、不可用类别和坐标差异。
- `checks.json` 的视觉状态真实，记录日期及所查看文件；说明修改后重新计算哈希。
- 只给本次范围内成品，不以结果为由擅自同步知识结论/索引。

## 技能维护测试场景

修改排版器或技能后，最小但有意义的验证：

1. **真实 CAT_1 离线回放**：完整输出 PDF/SVG/PNG；打开 PNG 和 PDF 渲染，对照冻结标准，检查六类轨道、02 区独立基因绿条及 F/R，源图哈希不变。
2. **坐标失败**：窗口反转、标记超窗、元数据 accession 错配或序列长度不足必须报错，不能出误导图。
3. **数据缺失**：轨道标题缺失时拒绝声称 loaded；已查证 unavailable 应显式标缺，仍生成其余部分。
4. **跨内含子分段**：两段 F 加 R 必须画三个独立矩形，按各段长度，不把间隙加进合成引物长度。远距离短片段必须另有局部窗，且局部矩形宽度 ≥ 8 px。
9. **外显子示意**：填写 `exons` 时，图上可见 `exon N` 与转录本 ID；引物段不得跨两个所列外显子。`mk` 或显示名含 `exN` 时必须填写 `exons`，且 N 等于落入的 `order`；错误号（如同一转录本上 F 为 11、R 为 13）必须报错。不填 `exons` 且名称无 `exN` 则不画。冻结 CAT_1 现含 `exons` 且 `mk` 为 `F`/`R`；无外显子回放须显式删除该字段。
10. **基因绿条**：冻结官方 SVG 宽 1094，尺标下有独立基因绿条且白字基因符号在带上；其下 XM_/XP_ 同行，不是绿/紫/红三行。缺绿条不得靠排版器补画。
11. **轨道层级顺序**：官方 SVG 内各 loaded 轨道必须严格满足 RefSeq -> Ensembl -> RNA-seq -> Variants 生物学层级。RNA-seq 或变异倒挂置顶时必须报错拦截，禁止误排版。
7. **组装对应**：填写 `assembly_info` 时，错误的 URL `id` 或序列不属于该组装必须报错。
8. **证据措辞**：笼统的“未收录密集公共变异数据”和湿实验结论不得通过校验。
5. **资源/写入保护**：HTML 错误页、外链 SVG、栅格 image 被拒绝；现有目录/受保护路径/符号链接不得覆盖；源哈希未变。
6. **真实 OpenCode 发现**：若当前 CLI 可用，通过 `opencode debug skill` 检查本技能名称和路径。不要为此启动远程模型任务、改模型或泄露全部配置。

这些测试不等于 Gemini 端到端运行。若没有实际让 Gemini 完成一次网页→导出→排版→视觉验收，不报告“Gemini 已验证可用”。
