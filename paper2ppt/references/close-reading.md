# 完整精读与实验讲解

## 范围和来源

完整覆盖正文、方法、全部图表图注及已提供补充材料，包括次要、阴性、矛盾结果、讨论和限制，再选择汇报组织。

1. 盘点章节、图表、补充文件及文中引用但缺失的材料。
2. 有转换材料时先通读 `full.md`，用 content list、model、layout 和 images 核查覆盖与定位；无转换时直接读 PDF，不强制重新转换。
3. 实际查看所有图表，结合方法、图注、正文理解。只读 OCR/图注属于文本解释，不是看图；无法直接查看时记录受影响图和未完成核查。
4. 精确数字、样本/物种/marker、方法条件、公式、页码/图号、转换缺失和语义疑点定点回查主 PDF。转换文本用于定位，不替代证据主 PDF。
5. 外部理解需求单列，按需要查权威来源，不自动通读全部参考文献。具体标准、定义或推导若非论文明确给出，单独注明出处和性质。

缺失补充材料记录名称、引用位置和受影响判断，不能由当前文件夹未见附件推断作者没有附件。继续其余阅读；用户明确缩小范围只能报告“指定范围完成”。大型数据表覆盖全部表页、字段说明和记录范围，记录程序化/分块范围；程序扫描不自动证明科学理解。原始数据、代码、视频分别记录检查方式和限制，精读不自动授权运行未知代码或复现所有分析。

## 给用户的笔记

`01` 正文按以下顺序，不把内部账本当第一份读物：

1. **摘要**：英文原文保留，按意群中英对照；评价另写，不能混入译文。
2. **引言**：汇总问题、缺口、本文定位，避免贴全文。
3. **主线框架**：先交代作者的实验/论证路线和对应章节、图表，再深入正文。此处是阅读导航，尚不等于批准汇报重组。
4. **正文配图**：沿原文路线逐项讲清实验，按下面的讲解规则展开。原图嵌在相应段落，中文解释放图外。背景和不影响理解的操作细节可压缩，不能把难懂的分组、计量和方法再压成总括。
5. **拟议汇报主线**：完整阅读后给出取舍及边界，标明待确认。
6. **附录**：覆盖表、主张记录、转换差异和未核查项。

必要讲解图保存到 `讲解图/`；完整图表视觉核查仍覆盖全部材料，不以是否嵌入笔记为界。

## 每项实验怎样讲清楚

先说明这项实验回答什么问题，再依次交代样本身份/来源、批次或系列、分组与对照、处理条件、输入量、测量方式、重复与指标；原文未提供的项明确说未报告。然后解释图表比较、观察、作者解释和结论边界。避免按清单机械堆段落，以读懂本结果为准。

编号与条件同时写出，首次出现的缩写解释中英文及本文含义。不同实验的样本集合不能混用：物种数、标本数、商品数、技术重复分别说明。复杂关系用就地辅助表格；解释实验分组与样本来源是不同问题，必要时分成两表，不另造脱离正文的术语库。实验安排（样本、分组、处理、测量、重复）与结果评价分开写。读表符号、达标判断、个别样品解读属于后者，不能充当前者。应用、市售、现场样本与实验室验收用同一套顺序。

读图先明确实验如何产生各条曲线/各组数据，标签表示预知样本身份、靶标还是分类结果；再读坐标、尺度、单位、分图、颜色/符号、比较及统计含义。读表说明列、分母、注释、阴性/反例和适用范围，不能只报结论。

## 数字、公式和难点答疑

- 解释顺序：所计量的对象 → 符号与单位 → 公式关系/分母 → 本文具体数字 → 能说明什么。浓度、总量、每反应输入量、比例不可混称；从浓度到总量需要体积等参数，缺失就不能算。
- 固定比较口径。质量比例、基因组份数、靶分子拷贝数和每细胞含量是不同层次，换口径需说明条件。标准品名义输入、仪器估计值、实际分子数分开表述，不把低浓度期望值说成每管精确有若干分子。
- 成对数字标明对象和顺序，解释各自的分母及测量方式，不能让用户猜斜杠两端是什么。单位变换及量纲核查后才给数值例子。
- 公式优先嵌 PDF 原式；符号和计算可用明文。仅在实际确认当前渠道能正确渲染时使用数学排版，不能交付未渲染 LaTeX。不要把本案例公式硬编码为通用公式。
- 演示计算标注假设值，和论文数据分开；缺少参数不从常见数值反推后冒充作者报告。查不到具体标准号、实验输入或附录时保留缺口。
- 用户反复表示未理解时，先定位卡点是对象、实验实施还是计量关系，给一个同口径具体例子并映射回原实验。不要仅换比喻或缩短定义。

论文事实、作者解释/推测、外部知识、教学示例、汇报者归纳分别可辨；不要求每句话贴标签，但在来源或推理层次变化处必须说清。标准比较见 [质量门](quality-gates.md)。

## 理解记录和制作承接

文末用一张覆盖表记录章节/图表/补充单元、状态（未读/已读待解/已理解）、实质理解、源位置、核查范围、缺口影响和汇报去向。阅读时去向可留空，完成后补。主张记录放同一文件，包含稳定编号、性质、来源、证据、支持程度和限定，不另建重复台账。

讨论解决的定义、分组和数字关系回填原讲解位置。分页时将已澄清的样本、分组、处理、测量与重复带入对应结果页并上屏，不能只留备注。结果评价按需上屏，不能代替实验安排。不能精读时讲清了、制作时却只剩图和一句结论。

完成检查覆盖全部材料而非仅选入 PPT 的部分。持有全文、勾选、文件存在、用户表示懂了都不能替代实质核查；影响整体理解的缺口未解不宣布完整精读完成。
