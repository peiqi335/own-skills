# 原始证据与辅助资产

## 资产边界

研究结果图、表、机制图和图形摘要只来自指定论文及补充材料。禁止生成、重绘数据或重建机制图，不能改变原图的结构、数字和颜色语义。允许忠实提取、裁切、等比例缩放和重复引用。

主文全部图表默认完整展示；可以同时提供局部放大、分图解释，但不能用局部替代整图整表或裁去反例。补充材料完整阅读后记录上屏/备注/不展开的去向及理由。

原表以原样图片保留。允许新增可编辑的分组、配样、术语关系和标准对照表，注明为据来源归纳的辅助解释，保留源位置，不冒充作者原表，不替代原始结果。禁止据原表数值重新绘图替换原图。

期刊封面是可选书目信息资产，可从指定材料或经核实的期刊官方来源获得，不属于研究证据，不作为任意外部装饰图的例外。找不到足够清晰版本时保留已知来源的限制或省略；不生成仿制封面。影响因子需要时核对来源、指标名及年度，不沿用其他年份的数值。

## 提取、比较与验证

1. 阅读时必要图用于 `讲解图/`；制作时只将实际用到的资产放入 `原图/`，可复用已经忠实核查的同一资产，避免重复裁图。
2. 比较源包原图、PDF 内嵌图和对应区域渲染。检查尺寸、文字/线条实际清晰度、完整性和目标显示大小；不凭“原图”名称或更大像素数选择。
3. PDF 内嵌图可能缺矢量文字或共用图例，低分辨率源放大也不会产生新细节。必要时用主 PDF 定点渲染，并在目标尺寸实际查看；不能把升采样当清晰度修复。
4. 保留坐标、单位、分图号、图例、统计、比例尺、对照和必要图注。完整裁切保留原表所有行列及脚注；共用图例随局部呈现。
5. 中文解释放图外，不改原图标签、颜色、对比度或符号，不补画缺失部分。遇到图中文字错误，可在图外说明，不直接改证据图。
6. 核对实际嵌入 PPT 的媒体是否是选定资产，再看渲染页面；提取目录里有清晰图不等于 PPT 用了它。

无合适图的背景/局限页可用文字，不用占位图冒充完成。关键图无法查看或缺失时报告受影响页，不能通过读取图注宣称已看图。
