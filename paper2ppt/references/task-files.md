# 任务文件与版本

默认根目录：用户当次指定位置优先；未指定则使用项目内 `6.文献汇报/`，不存在则询问。

核实身份后助手生成 `第一作者_年份_简短题名` 并展示，移除目录名中的路径分隔符等非法字符，不改源名称。用 DOI/源 SHA-256 辅助匹配已有任务，同篇续接。同名不同篇加短 DOI，无 DOI 加源哈希短前缀；不只凭简称合并。

按阶段建文件，不预建空文档，不改 Vault 入口。内部附件/页面用 Wiki 链接，外部网站用 Markdown；Vault 外专属页面按仓库跨 Vault 规则记录路径与链接。

```text
第一作者_年份_简短题名/
├── 00.任务进度.md
├── 01.精读笔记.md
├── 02.讨论与汇报主线.md
├── 03.逐页安排.md
├── 04.原图清单.md
├── 05.验收记录.md
├── 原图/
│   ├── Fig01_full.png
│   ├── Fig02_panel_a.png
│   └── Fig02_shared_legend.png
└── 汇报/
    └── 第一作者_年份_文献汇报_v01.pptx
```

| 文件 | 时机 | 内容 |
|---|---|---|
| 00.任务进度.md | 身份核实后 | 标题/作者/年份/DOI，主文献及补充文件链接和 SHA-256，材料清单，来源充分性与实际阅读范围，语言/听众/时长/重点，阶段、待答点、下一步、最新产物链接 |
| 01.精读笔记.md | 阅读时 | 覆盖与理解、主张来源对应、全部图表解读、方法、限定和疑点 |
| 02.讨论与汇报主线.md | 首次讲全貌时 | 原文逻辑和来源、断点、讨论结论、待决问题、拟议主线、取舍理由；用户修订、确认内容/日期/自然语言依据 |
| 03.逐页安排.md | 主线确认后 | 页号、目的、标题、主张编号、图/分图、读图说明、限定、过渡、时间估算；不入选理由回填精读笔记 |
| 04.原图清单.md | 首次提取汇报图时 | 文件链接、源文件/哈希、页码、图表号/分图、提取/裁切方式、保留与排除标签说明、目标页和主张 |
| 05.验收记录.md | 制作检查时 | 当前 PPT 链接/版本/哈希、各质量门证据、缺口、修订及未执行项 |
| 原图/ | 准备汇报图片时 | 实际使用的原样提取/忠实裁图，不预复制全文全部图 |
| 汇报/ | 正式导出时 | 版本化可编辑 PPTX |

阶段用识别材料、阅读中、讨论中、待主线确认、制作中、待验收、已交付；可附暂停与阻塞说明。进度不替代质量状态。记录有效决策，不复制聊天流水账。

## 保存与恢复

- 源 PDF、全文、JSON、图片只读且留原处，不移动或复制整包，不自动沉淀正式知识。
- 更新前先读文件，保留用户补充与确认。新决定记明取代哪项，不把建议静默写成批准。
- 临时文件放 `/tmp/paper2ppt/<任务标识>/<运行标识>/`：预览、联系表、构建脚本和结构检查原始输出。必要的 PPT 渲染中转 PDF 仅放这里，不是文献转换产物或交付 PDF。
- 决策、来源映射和恢复信息持久保存；临时文件失效可据此重建，不宣称临时构建永久可用。
- 试稿临时迭代；首交 v01，交付后修改取下一未占用版本，旧版不覆盖。非中文任务调整语言文件名，版本规则不变。
- 笔记指向最新版本；原图清单目标页标适用版本，验收保留旧版摘要，不把旧检查套到新稿。
- 用户明确另做不同场次时才建 `场次/<场次名>/`。根目录共享 00/01；既有 02–05、原图、汇报留原处，新场次的 02–05、原图、汇报放场次目录。00 登记当前场次，新场次引用共享精读笔记，不搬迁旧成果。
- 不批量清理既有目录，不默认交付 PDF、XLSX、重复台账或独立讲稿；讲述内容在 PPT 备注。

恢复先读 00，再读当前阶段所需内容；源哈希/版本变化时核查影响，候选不唯一请用户选择。
