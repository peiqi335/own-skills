# 行为验收案例（仅维护时读取）

目标是观察技能是否改善实际决策与产物，不检查代理是否复述规则。用临时副本/合成数据运行，论文、最终稿和用户任务文件只读。每次记录请求、给定材料、实际输出、判定依据和限制；格式检查不能代替行为验证。

独立测试时只给评估代理用户请求、技能和最小原始材料，不提供本表的预期结果。主代理收到输出后再按下表判定。科学结论由主代理复核，机械核对可委派；模型/推理档位遵从当前任务约定，不绑定特定供应商。

| 场景与输入 | 要观察的行为 |
|---|---|
| 新论文，有全文、全图表及一个被引用但缺失的补充表；用户说“先带我读懂” | 先给可读讲解，说明补充缺口，覆盖方法/图注；不直接制 PPT，不宣称所有材料完整 |
| 用户追问一个公式、两个并列数字和稀释起点；材料只给浓度，没给体积 | 固定对象、单位和数值顺序；区分浓度与输入量；不补体积算总量，不用未渲染公式替代解释 |
| 用户认为原文开头方法太密，要求按问题组织，并已确认主线 | 给可对照的分页内容，保留实验依赖；不固化问题数，不虚构方法步骤的配图/结果；缺材料仅给标明缺口的阶段方案，不在尚未确认分页时自行制成品 |
| 原文有完整密集结果表，还需解释样本配制；用户确认制作 | 保留原表；另加有来源的可编辑辅助表；实际页面有方法与分组，不把它们全塞备注 |
| 原文有市售或应用结果表，样本构成与测法写在方法段；用户确认制作 | 结果页先上屏样本构成、分组、处理、测量与重复；不把读表符号或个别样品评价当成分组；不把这五项只写进备注 |
| 合成标准规定“≤0.09% 或 ≤50 copies”，结果为0.1%、40 copies，其他条件未报告 | 识别替代条件与缺失条件，不能仅因0.1大于0.09判失败，也不能因40小于50宣布全面通过 |
| 当前稿标题/标签/位置被用户手改，旧脚本仍保留旧值；用户只要求改一处数字且就地保存 | 读取当前稿并保护检查点，局部修改；手改与无关页保留，旧脚本不直接覆盖，同步受影响备注/记录 |
| 图片读取失败、导出超时或恢复时记录仍停在“待确认” | 如实区分文字解释与看图、计划与保存成功；查文件与有效授权恢复，不重复审批或虚报完成 |

## 代表页实际制作测试

从已确认分页中选择方法页、密集结果页和结论页，仅用指定来源制作隔离的可编辑三页试稿。取一份当前 PPT 作视觉参考，不能修改正式文件。

评估实际 PPT 的标题/问题归属、承诺上屏解释、原图表完整性、辅助表可编辑性、来源/备注，以及结论原文与归纳的区分。核对渲染单页和总览；结构检查另记。若工具无法完成，披露具体未验证部分，不能用大纲或原稿截图冒充制成测试。

通过这组测试只说明上述场景和所测页面通过，不说明任意新论文精读或下一轮完整工作流已验证。复测仅针对新修改、失败项及其影响范围。
